Sobre o sistema

O MAPA (Mapeamento, auditoria e processos Avaliados) é um sistema centralizado e desenvolvido para otimizar, autorizar e simplificar a gestão da Gerência de Auditoria Interna FUSVE. Através de uma interface intuitiva, a plataforma reúne as ferramentas necessárias para os auditores armazenar os dados informados e coletados pelas áreas auditadas. Atua como uma engrenagem integrada onde pessoas, processos e produtos estão intercalados.

A implementação desse sistema elimina tarefas manuais repetitivas, reduz a margem de erros e garante que toda a equipe trabalhe em sintonia. Com a centralização das informações, ganha agilidade nas operações, melhora a comunicação interna e tem total controle sobre os resultados, transformando dados em decisões estratégicas.

História do sistema

Passe o mouse sobre os pontos para ver imagens
FEV / 2026

Início do Projeto

Desenvolvimento da primeira solução para automatizar e integrar a metodologia de trabalho.

MAR / 2026

Desenvolvimento da V.1

Desenvolvimento do sistema na V.1 utilizando Python como linguagem de programação e a biblioteca streamlit para a interface.

ABR / 2026

Aprimoramento da V.1

Aprimoranto a V.1 para a V.2 ainda utilizando Python + Streamlit, mas devido às complexidades que foram sendo agregadas no desenvolvimento do projeto, foi necessário implementar uma nova interface.

MAI / 2026

Desenvolvimento da V.2

Estabelecimento da V.2 utilizando linguagens de programação como Python para o Backend e HTML + CSS + Javascript para o Frontend, melhorando a interface e possibilitando a geração de valor conforme novas complexidades foram sendo agregadas ao projeto.

JUN / 2026

Estabelecimento da versão para produção

A estimativa é que até o final do mês, o sistema já esteja funcionando em ambiente de produção, capaz de colher dados de cada auditoria em execução e a que estão por vir.

2026...

Melhoria Contínua

Estimamos a implementação de uma inteligência artificial no sistema, de modo que possa contribuir positivamente com o auditor, auxiliando nas identificação de riscos, análises e geração de conclusões à respeito de cada auditoria.
